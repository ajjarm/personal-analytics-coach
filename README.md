# Personal Analytics & AI Coach

A cross-platform habit, journal and health-tracking platform with an LLM coach grounded in my own data, in daily personal use since November 2025.

**Stack:** TypeScript, PostgreSQL, Cloudflare Workers, Llama 3.3

## Highlights

- watchOS companion app
- Sleep, nutrition and screen-time data ingestion
- A 30-tool MCP server that gives the LLM coach grounded access to my own data
- Next-day habit completion modelled with L2-regularised logistic regression, beating a historical baseline under walk-forward validation (Brier score 0.18 vs 0.22)
- Block permutation tests with Benjamini–Hochberg control to find statistically robust patterns
